# 邻传 (Connections)

零服务器、跨平台局域网点对点（P2P）文件、文件夹与文本即时互传工具。

## 核心特性

- **零配置局域网发现**：基于 UDP 组播（`224.0.0.167:53317`）、子网广播与 HTTP 心跳机制，同一局域网设备上线即见，支持 IP 尾段短码（如 `#27`）快速连接与 `/24` 子网并发扫描。
- **双模点对点高速传输**：
  - **直连多路并发流式推流**：支持单文件、多文件并发（Keep-Alive 4 路流水线）与文件夹完整目录层级递归传输。
  - **自动反向拉取（Reverse-Pull）**：自动穿透 Android 模拟器（`10.0.2.16`）及单向防火墙限制。
- **Web 扫码免安装互传**：内置零依赖网页端，局域网内任意手机或电脑浏览器扫描二维码即可向本机发送文件与文本。
- **剪贴板与文本秒传**：一键将当前系统剪贴板或文本链接投递至目标设备。
- **可靠与安全保障**：
  - 每次传输动态签发一次性 `X-Upload-Token` 鉴权令牌；
  - 接收文件采用 `.part` 临时文件流式落盘 + 字节完整性校验后原子重命名，杜绝断网半截损坏文件；
  - 支持免确认自动接收开关及单设备信任授权管理。

## 跨平台构建

```bash
# 获取依赖
flutter pub get

# 构建 Android 生产版 APK
flutter build apk --release

# 构建 macOS 生产版应用
flutter build macos --release

# 构建 Windows 生产版应用（在 Windows 环境下执行）
scripts\build_windows.bat
```
